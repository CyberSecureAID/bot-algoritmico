Governance & upgrades

Every contract is a UUPS proxy (ERC-1967). Ownership and permissions are centralized in the Tarifas contract, which holds the fee registry and the owner set: a principal owner plus a limited number of directors. Logic upgrades run through an on-chain timelock of 48 hours. A new implementation is published on chain and can only take effect after those 48 hours, so the exact code is public and auditable before it runs. On every upgrade the storage layout is checked slot by slot, so no upgrade can silently corrupt existing state. No contract can move assets out of your wallet without your signature, and the platform never takes custody of user funds.

Open source & verifiable

The full source is public at github.com/CyberSecureAID/bot-algoritmico, and for every contract here both the proxy and the implementation are verified on BscScan. The web app ships as native ES modules served directly from the repository, with no build, bundling or minification step, so the JavaScript running in your browser is the public source itself. Any reviewer can fetch a file the site serves, diff it against the repository, and confirm they match. There is no compiled or obfuscated layer in between.

What you actually sign

Connecting a wallet is read only: it reveals your address and balances and grants no spending allowance. Every action is a standard, auditable transaction: an ERC-20 approval scoped to a single router or contract, a swap, or a service fee payment, sent only to the verified contracts on this page. You are never asked for a seed phrase or a private key; the site has no field to enter one and no contract can request it. The site loads no advertising or analytics scripts and makes no third-party calls beyond the public RPC and price oracles it needs to run.
