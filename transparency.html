Verify it yourself

Nothing here asks for trust. Every contract below is deployed on BNB Smart Chain and verified on BscScan, proxy and implementation, with a bytecode match, so you read the exact code that runs. The web app is served to your browser as the same native ES module files published in the repository, with no build, bundling or minification step, so you can open any file the site loads and diff it against GitHub line for line. The full commit history is public. There is no private backend deciding what happens to your funds, and no compiled layer hiding what the code does.

Your funds never leave your wallet

The platform is non-custodial by design, not by promise. There is no deposit, no pooled balance and no account that holds user funds. Every bot trade, swap, limit order and futures position executes directly from your own wallet through transactions you sign. Token access is granted with ERC-20 approvals scoped to a specific, named router or contract, never an unlimited allowance, and no contract can pull assets from your wallet without your signature for that action. Because nothing is ever held in custody, there is no central balance that could be drained or frozen.

Upgrades on a public clock

Each contract is a UUPS proxy (ERC-1967), and upgrade authority sits in one auditable place, the Tarifas contract, under a multi-owner model. No upgrade can take effect instantly. A new implementation is proposed on chain and held for 48 hours before it can be activated, so the exact new bytecode is public and open to review during that window, and both the proposal and the activation are visible on chain. The storage layout is preserved and checked slot by slot on every upgrade, so state cannot be silently rewritten. This is the full control surface, and it is the same for everyone looking at it.
