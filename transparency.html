Governance & upgrades

Every contract is a UUPS proxy on the ERC-1967 standard. Ownership and permissions are held in one place, the Tarifas contract: a principal owner and a limited set of directors, readable on chain. A logic upgrade cannot be pushed instantly. The new implementation is proposed on chain and a timelock of 48 hours must pass before it can be activated, so its exact bytecode is public and reviewable before it ever runs. The storage layout is preserved and checked slot by slot on every upgrade, so no upgrade can quietly corrupt existing state. No contract holds user funds or can move assets from your wallet without your own signature.

Open source & verifiable

The full source is public at github.com/CyberSecureAID/bot-algoritmico, and for every contract here both the proxy and the implementation are verified on BscScan with a bytecode match. The web app is not bundled or minified: it is served to your browser as the same native ES module files that live in the repository. A reviewer can open any file the site loads, compare it to the repository line for line, and confirm they are identical. There is no compiled, packed or obfuscated layer between the public source and what runs.

What you actually sign

Connecting a wallet only reads your address and balances; it grants no spending allowance and moves nothing. Every action is a plain, auditable transaction: an ERC-20 approval scoped to one named router or contract, a swap, or a service fee, and it is sent only to the verified contracts listed here. You are never asked for a seed phrase or a private key; the page has no field for one and no contract can request it. The page loads no advertising or analytics code and calls no outside service beyond the public RPC and the price oracles it needs to work.
