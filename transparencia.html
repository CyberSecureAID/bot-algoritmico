Governance & upgrades

Every contract is a UUPS proxy (ERC-1967). Authorization is centralized in the Tarifas contract, which holds the platform's fee registry and its owner set — a principal owner plus a limited number of directors. Logic upgrades are gated by an on-chain 48-hour timelock: a new implementation must be proposed on-chain and can only be activated after 48 hours have elapsed, leaving a public window to review it before it goes live. Storage layout is preserved and checked slot by slot across upgrades, so an upgrade cannot silently reshape existing state. No contract can move assets out of your wallet without your explicit transaction signature — the platform is non-custodial and never takes custody of user funds.

Open source & reproducible

The full source lives at github.com/CyberSecureAID/bot-algoritmico, and both the proxy and the implementation of every contract shown here are source-verified on BscScan. The web app ships as native ES modules served straight from the repository — no build, bundling or minification step — so the JavaScript running in your browser is the public source itself. Any reviewer can fetch a file served by the site and diff it against the repository to confirm they are identical; there is no compiled or obfuscated layer in between.

What you actually sign

Connecting a wallet is read-only: it exposes your address and balances and grants no spending allowance. Each action you take is a standard, auditable transaction — an ERC-20 approval scoped to a specific router or contract, a swap, or a service-fee payment — sent only to the verified contracts on this page. You are never asked for a seed phrase or private key; the site has no field to enter one and no contract can request it. No advertising or analytics scripts are loaded, and the site makes no third-party network calls beyond the public RPC and price oracles it needs to operate.
